# ESWIN kernel
This repo contains build artifacts for Fedora kernels.

Patches are generated from https://github.com/jmontleon/linux-eswin

Patches were taken from cmirabil on gitlab.com [https://gitlab.com/cmirabil/kernel-ark](https://gitlab.com/cmirabil/kernel-ark/-/tree/stable_eswin)

For LTS kernels based on the rockos kernel source see [jmontleon/linux-rockos-rpm](https://github.com/jmontleon/linux-rockos-rpm)
